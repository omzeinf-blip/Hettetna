# حِتّتنا | HETTETNA

موقع وساطة عقارية عربي (RTL) لمدينتي 6 أكتوبر والشيخ زايد، مبني بـ **Next.js 15** و**Supabase**، ومعه لوحة إدارة عربية لإدارة العقارات والمشروعات واستفسارات العملاء **دون تعديل الكود**.

## ماذا يشمل المشروع؟

- **الموقع العام**: الرئيسية، العقارات (بحث وفلاتر وترتيب وصفحات)، تفاصيل العقار، المشروعات، من نحن، تواصل معنا، أضف عقارك، سياسة الخصوصية، صفحات الأخطاء، SEO وSitemap وRobots.
- **لوحة الإدارة** `/admin`: تسجيل دخول بالبريد وكلمة المرور، إدارة العقارات والمشروعات (إضافة/تعديل/نشر/إلغاء نشر/حذف)، رفع الصور، صندوق استفسارات العملاء (الحالة والتعيين والملاحظات)، وإعدادات بيانات التواصل.
- **قاعدة البيانات**: Migration جاهز (`supabase/migrations`) يُنشئ الجداول وسياسات الأمان (RLS) ومخزن الصور.
- **حماية النماذج**: تحقق على الخادم، حقل مصيدة للروبوتات، وحد لعدد الطلبات مخزَّن في قاعدة البيانات.

## المتطلبات

- Node.js **22 أو أحدث** (للتشغيل المحلي والاختبارات).
- مشروع Supabase (موجود لديك).
- حساب استضافة، والموصى به **Vercel** (مجاني للبداية).

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local      # على ويندوز: copy .env.example .env.local
# عدّل .env.local (انظر docs/SUPABASE.md)
npm run dev
```

افتح http://localhost:3000

> **للمعاينة بدون قاعدة بيانات** اجعل `NEXT_PUBLIC_DEMO_MODE=true` في `.env.local`. ستظهر عقارات تجريبية **مُعلَّم عليها بوضوح** ولن تُحفظ أي نماذج. في الإنتاج يجب أن تكون القيمة `false`.

## أوامر الفحص

```bash
npm run typecheck   # فحص TypeScript
npm run lint        # فحص الكود
npm test            # الاختبارات الآلية (42 اختبارًا)
npm run build       # بناء نسخة الإنتاج
```

## هيكل المشروع

```
src/app/(site)/        الصفحات العامة
src/app/admin/         لوحة الإدارة (محمية)
src/app/api/           نقاط الـ API (الاستفسارات، رفع الصور)
src/lib/data/          طبقة البيانات (Supabase) والبيانات التجريبية
src/lib/admin/         الجلسات والتحقق وأدوات الإدارة
src/middleware.ts      حماية مسارات /admin وتجديد الجلسة
supabase/migrations/   ملف الـ Migration
tests/                 الاختبارات الآلية
```

## ما الذي يجب أن تفعله بنفسك؟

1. الموافقة على الـ Migration وتشغيله (الخطوة 2 في docs/SUPABASE.md).
2. إنشاء أول مدير (docs/SUPABASE.md) وتعطيل التسجيل العام في Supabase Auth.
3. إضافة متغيرات البيئة في الاستضافة (`.env.example`)، ومنها المفتاح السري **في إعدادات الاستضافة فقط**.
4. نشر الموقع وربط الدومين (docs/DEPLOYMENT.md).
5. مراجعة سياسة الخصوصية قانونيًا ثم ضبط `NEXT_PUBLIC_PRIVACY_REVIEWED=true`.
6. إضافة العقارات الحقيقية من لوحة الإدارة وبيانات التواصل المؤكدة من صفحة الإعدادات.
7. إضافة بيانات الشركة الرسمية (الاسم القانوني، السجل التجاري، ترخيص الوساطة) واستبدال الصور الأرشيفية بصور حقيقية (انظر docs/CONTENT-AND-TRUST.md).
