# النشر على Vercel

## قبل البدء

نفّذ محليًا وتأكد أنها تنجح: `npm install` ثم `npm run typecheck` و`npm run lint` و`npm test` و`npm run build`.

## 1) رفع المشروع

1. ارفع المجلد إلى مستودع (GitHub مثلًا). **لا ترفع** `.env.local` ولا `node_modules` (مستبعدان في `.gitignore`).
2. في Vercel اختر **Add New → Project** واستورد المستودع. الإعدادات الافتراضية لـ Next.js صحيحة (Build: `next build`).
3. تأكد أن إصدار Node في إعدادات المشروع **22.x**.

## 2) متغيرات البيئة

أضفها في **Settings → Environment Variables** (بيئة Production على الأقل):

| المتغير | القيمة |
|---|---|
| `SUPABASE_URL` | رابط مشروع Supabase |
| `SUPABASE_ANON_KEY` | المفتاح العام |
| `SUPABASE_SERVICE_ROLE_KEY` | المفتاح السري (علّمه كـ Sensitive) |
| `RATE_LIMIT_SECRET` | نص عشوائي طويل |
| `NEXT_PUBLIC_SITE_URL` | `https://دومينك` |
| `NEXT_PUBLIC_DEMO_MODE` | `false` |
| `NEXT_PUBLIC_PRIVACY_REVIEWED` | `false` الآن، و`true` بعد المراجعة القانونية |

بعد أي تغيير في متغيرات `NEXT_PUBLIC_*` أعد النشر (Redeploy) لأنها تُدمج وقت البناء.

## 3) ربط الدومين وHTTPS

1. من **Settings → Domains** أضف دومينك.
2. أضف سجلات الـ DNS **كما تعرضها Vercel بالضبط** عند مزوّد الدومين (قد تختلف حسب النوع).
3. شهادة HTTPS تُصدر تلقائيًا بعد ظهور الدومين كـ Valid.
4. حدّث `NEXT_PUBLIC_SITE_URL` بالدومين النهائي ثم أعد النشر.

## 4) اختبار ما بعد النشر

- [ ] الصفحة الرئيسية وجميع روابط القائمة تفتح بدون أخطاء.
- [ ] `/properties` بدون عقارات تعرض رسالة «عقارات جديدة قريبًا» (وليس خطأ).
- [ ] `/admin` يحوّلك إلى `/admin/login` وأنت غير مسجّل.
- [ ] تسجيل الدخول بحساب المدير ينجح؛ وبحساب غير موظف أو كلمة خاطئة يفشل بنفس الرسالة العامة.
- [ ] أضف عقارًا تجريبيًا ← ارفع صورة ← انشره ← يظهر في `/properties` والرئيسية ← ألغِ نشره ← يختفي.
- [ ] أرسل استفسارًا من صفحة التواصل ← يظهر في **الاستفسارات** بالإدارة.
- [ ] أرسل 6 طلبات متتالية ← الطلب السادس يُرفض برسالة «عدة طلبات في وقت قصير».
- [ ] افتح `/sitemap.xml` و`/robots.txt` (يجب أن يمنع `/admin` و`/api`).
- [ ] جرّب الموقع على موبايل وكمبيوتر.
- [ ] نفّذ اختبارات الصلاحيات في [SECURITY.md](SECURITY.md).
- [ ] احذف أي عقار تجريبي أنشأته للاختبار.

## تحديثات لاحقة

أي تعديل على العقارات والمشروعات والتواصل يتم من لوحة الإدارة وينعكس على الموقع خلال نحو دقيقة، بدون نشر جديد.
